💡 CUSTOMIZATION TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MODIFY PLANET COLORS
  → Edit PLANETS_DATA in main-solar.js
  → Change color, metalness, roughness

ADJUST BLOOM EFFECT
  → Line ~1000 in main-solar.js
  → Modify UnrealBloomPass parameters

CHANGE ANIMATION SPEED
  → Edit orbitSpeed in PLANETS_DATA
  → Modify rotationSpeed values

TOGGLE FEATURES
  → Comment/uncomment effects in setupPostProcessing()
  → Disable certain lights for performance

MOBILE QUALITY
  → Edit selectQualitySettings() in PERFORMANCE_OPTIMIZATION.js
  → Adjust particleCount, geometrySegments

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Scene doesn't appear?
  → Check browser console for errors
  → Verify WebGL support (get.webgl.org)
  → Update GPU drivers

Performance is slow?
  → Run in Chrome (best performance)
  → Close other browser tabs
  → Check GPU usage in DevTools

Interactions don't work?
  → Check GSAP is imported
  → Verify JavaScript console
  → Try different browser

Need help?
  → Read documentation files
